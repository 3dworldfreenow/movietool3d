# Real sound recordings (optional)

Drop recordings here and the engine uses them instead of its synthesised sounds.
**Only free-to-use recordings: CC0 / public domain** (no credit, any use, also monetised videos).

| File name | Used for |
|---|---|
| `rain.ogg`, `rain_2.mp3` ... | the rain bed: looped, louder and softer with the rain in the scene |
| `wind.ogg`, `wind_2.ogg` ... | the wind bed, the same way |
| `thunder.ogg`, `thunder_1.ogg`, `thunder_2.ogg` ... | claps of thunder - a different one each time |
| `<effect>.wav` (e.g. `car_door.wav`, `phone.wav`) | any single effect, by its name |

Formats: ogg, mp3, wav, flac, m4a. A missing file = the synthesised sound, as before.

**Easiest: the 🔊 Sounds panel** on the Stick 2.5D / Stick 3D pages lists the sounds your story uses (✔ real
recording, ○ built-in), plays them (▶) and takes an upload for each name - it saves the file here with the right
name. Uploaded sounds are not put in git (they stay on the machine that has them).

Good CC0 sources (check the licence on each file's page before adding it):
- OpenGameArt "Rain + Long Thunder" (WuxiaScrub, CC0): https://opengameart.org/content/rain-long-thunder
- OpenGameArt loopable rain (Ylmir, CC0): https://opengameart.org/node/55302
- itch.io "Rain and Thunder" (cluckfox, CC0, 24-bit FLAC): https://cluckfox.itch.io/rain-and-thunder
- Freesound.org with the licence filter set to "Creative Commons 0"

Write each file's source and licence in the list below when you add it.
