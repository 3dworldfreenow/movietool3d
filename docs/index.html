Stick 3D is a doodle 3D film engine. A story JSON goes in, a voiced MP4 comes out: places, people, animals, camera moves, voices, music and subtitles. Free, open source, runs on your own computer.

How it works

You describe the film. The engine builds the world, places the camera, acts every line and edits it together.

IdeaPaste the Stick 3D prompt into any AI with your idea, or write the JSON yourself.
Story JSONCharacters, places, scenes, lines and moods: one plain text file.
Checkvalidate and storyboard show every shot in seconds, before rendering.
MP4Voices, lip sync, music, sound effects and subtitles, rendered to video.

Made with Stick 3D

Real frames from Bhediya Aaya! (The Boy Who Cried Wolf), straight out of python main.py storyboard stories/village_tales/bhediya_aaya.json.

What’s in the box

Everything a short film needs, drawn in code. No 3D models to buy, no editor to learn.

🏡 Places

Villages, fields, roads, rooms and big 3D world maps, built from a short list.

🎥 Cinema

Wides, two-shots, close-ups, tracking and slow push-ins, chosen for each line.

🗣️ Voices

Offline Piper voices or free online Edge voices, with lip sync and many languages.

🐺 Animals

40 animals and birds that walk, graze, fly and act alongside the people.

🌅 Mood & light

Day, dusk and night, a colour script per scene, sky, grain and effects.

🌐 Web page

Paste or upload a story, press Render, watch or download the video.

Get started

Python 3.10+ and FFmpeg. Linux, macOS or Windows.

1. Install

git clone https://github.com/3dworldfreenow/movietool3d
cd movietool3d
pip install -r requirements.txt
# offline voices (~0.7 GB), or use --tts edge
python tools/get_piper_voices.py

2. Render

python main.py render stories/village_tales/bhediya_aaya.json \
  --tts piper --resolution 1280x720 --no-hook

3. Or use the web page

STICK3D_PASSWORD=your-secret \
  python stick3d_server.py --host 0.0.0.0 --port 8000

A story is just JSON

{
  "title": "Bhediya Aaya!",
  "settings": { "language": "en-IN", "art": "stick3d",
                "music": "raga_happy" },
  "characters": {
    "raju": { "name": "Raju", "age": "child",
              "shirt": "#e8b23a", "skin": "brown" },
    "wolf": { "name": "Wolf", "species": "wolf" }
  },
  "scenes": [
    { "id": "b1_village",
      "stick_place": "village_road",
      "stick_shot": "village_high",
      ... }
  ]
}

Don’t want to write it? Paste the Stick 3D prompt into any AI with your idea, then paste the answer into the web page.
